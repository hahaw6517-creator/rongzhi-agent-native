# 自然语言调整与临时情景

当前对话由 DeepSeek 理解用户意图并提取参数，Python 核对原文、单位、变化方向、基准与范围，再执行融资求解及风险复算。用户不需要填写 JSON 或按固定句式输入。

- 修改需求或参数默认生成临时方案，正式财报及报告保持不变；选择采用后才准备更新确认。
- 单独查询融资上限使用当前一年期模型，不需要用户先提供目标金额。
- 金额未给单位、调整幅度不清楚、多个可能基准或超出模型范围时先追问。待补充要求按企业及当前报告指纹保存，可继续补充、讨论概念或取消。
- 用户明确基于上一临时方案继续时，继承对应情景；默认基于正式报告。上传其他企业或正式分析条件改变后，不继承旧企业的待澄清要求。
- 多项调整先全部验证再计算，不静默执行其中一部分；模型未调用必要工具时不能宣称已经重算。

## 开放的参数

净融资需求；各渠道独立年利率、手续费率、固定费用、本金上限（设零可禁用）；统一参考利率；信用额度收入折算比例、抵押资产融资比例、应收融资比例；负债率上限、偿债覆盖安全线、现金储备天数；收入增长情景、维持性投资比例、预测误差修正比例和限幅；压力现金下降幅度、加息幅度、回款延迟天数、毛利率下降幅度；CVaR置信水平和权重。

产品包括信用、抵押、应收账款质押三类。独立利率覆盖仅作用于指定渠道。增减百分点与相对百分比增减区别处理；计算直接读取当前基准，不要求大模型心算最终值。

## 模型边界

仍固定12个月生产经营周转。范围外的期限、用途、新产品、新算法需要扩展模型，不能靠文字生成冒充计算。用户可调整的假设均有明确数值范围；历史结构约束及已核验市场压力可能比用户参数更紧，需要在结果中说明。

接口断连、计算未收敛或验证失败时不给出虚假的新结果，保留要求和原报告，并说明下一步。自然语言理解不能保证每种表述都一次成功；不明确就持续澄清，用户也可取消。
