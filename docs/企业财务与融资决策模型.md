# 企业财务与融资决策模型

## 规划范围

同一企业三个连续完整年度，固定12个月生产经营周转融资。数据由用户按模板上传并标明年份。计算使用报表原值，页面金额以亿元展示。仅预测最新财报年度的下一完整年度，不把年度情景描述为逐月经营预测。

## 财务分析

先核验报表完整性和勾稽，再计算指标。诊断分为资产负债、应收与固定资产、营运资金、现金流、盈利归因五块，各块给出结论、必要数据和决策含义。盈利分解解释利润率、效率和杠杆的代数贡献，不将利润增长自动转换为可借金额。

以前两年预测第三年，计算一次有符号误差；使用最近两年的现金转化与收入情景预测下一年，再按可调比例及限幅转移部分误差。单次误差校正不证明预测精度改善。维持性投资、存量本息等包含报表代理假设，需与真实预算及合同区别。

## 融资决策

候选为信用流动资金贷款、抵押流动资金贷款、应收账款质押流动资金贷款。本金为连续变量，渠道启用为二元变量。阶段一最大覆盖扣费后净需求；阶段二保持覆盖水平，最小化一年利息费用与加权情景 CVaR。默认置信水平80%、权重0.1，属于公开可调的模型偏好。

约束包括需求范围、产品启用及容量、资产负债率、压力情景现金覆盖、经营用途规模。按固定组合独立核对支付时点敏感性、现金储备和资金闭合。产品容量是基于报表和融资比例的规则池，不是银行批复额度，账面应收或固定资产也不是已核验担保物。

## 风险评估

检查基准、现金承压、回款延迟、毛利下降、加息及联合压力六个情景；逐个列明参数及现金影响。展示可用于偿债的现金、本息、覆盖倍数、安全线缺口及逆向压力边界。

CVaR 汇总相对基准的偿债后现金余量下降，不是贷款损失或现金不足额。六情景等权是设计假设，不是实际发生概率；本流程不报告蒙特卡洛违约概率。

## 对话与报告

AI 模型获得当前企业报表、Python 分析、市场证据、知识资料和对话背景，理解问题并调用工具。临时情景由 Python 重算并验证，采用后才更新正式分析。含糊、越界或不支持的要求先澄清；不能执行任意新算法或编造数字。

报告提炼财务结论、融资配置、约束与风险、调整建议，以 Word 下载，不重复逐项列出全部详细分析。
