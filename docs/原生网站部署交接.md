# 原生网站部署交接

本仓库对应 `融智agent - 副本` 的原生网站版本。旧 Streamlit 界面文件仅保留兼容，部署时不要选择 `streamlit run app.py`。

## 当前功能范围

- 导入用户标明年份的连续三年财务数据，金额展示单位为亿元。
- 固定规划期为一年，用途为生产经营周转。
- Python 执行财务指标、诊断、一次历史预测校验与下一年现金情景、融资产品筛选、融资组合优化、压力测试和独立验证。
- DeepSeek 用于需求理解、工具选择和结果解释；决策对话支持多个参数的临时情景，采用后才更新正式分析。
- 分析报告下载为 Word 文件。

## 安装和启动

建议 Linux + Python 3.12，在仓库根目录执行：

```sh
python -m venv .venv
.venv/bin/python -m pip install -r requirements-web.txt
.venv/bin/python -m uvicorn web_app:app --host 0.0.0.0 --port 8000 --no-server-header
```

托管平台若分配了 `PORT` 环境变量，可用 `.venv/bin/python web_app.py`，并设置 `HOST=0.0.0.0`、`PORT=平台要求的端口`。容器使用已安装依赖的 Python 时，不需要命令中的 `.venv/bin/` 前缀。

## 配置

在平台环境变量或服务器私有 `.env` 中设置：

- `DEEPSEEK_API_KEY`：由项目所有者私下配置，不提交 GitHub。
- `BASE_URL=https://api.deepseek.com`
- `MODEL`：与原项目实际使用的配置保持一致，示例见 `.env.example`。
- `TAVILY_API_KEY`：可选检索服务密钥；不配置不等于能够保证检索覆盖所有企业。
- `FINBRIDGE_DB_PATH`：建议设为持久化目录中的 SQLite 文件路径。

数据库默认在 `data/runtime.sqlite3`，未上传 GitHub。平台临时文件系统不能作为长期存储。初次部署会使用新的会话数据，不包含本机上传记录或聊天历史。

## 文件与数据

原生入口是 `web_app.py`，页面资源在 `web/`，算法在 `src/finbridge/`。`data/` 中包括正式模板和公开演示数据。

`output/真实企业案例/` 中仅提交网站下载路由需要的四个官方财报 Excel，不包含用户运行报告、日志或会话。复制部署时应保留这些文件的相对目录。福耀玻璃、中国中免是自行上传测试文件，上传仓库不代表已执行其融资分析。

## 上线验收

确认网页打开、Excel 模板下载与上传、分析执行、临时对话情景、Word 下载均正常。测试不同浏览器会话隔离，配置 HTTPS、异常重启、运行监控和调用用量限制。建立数据库一致性备份及恢复流程，原生网站本身不等于已配置完这些云端运维措施。

后续自动更新只连接这个新仓库。保留旧仓库现有 Streamlit 部署，不将旧仓库设置为本网站的代码来源。
