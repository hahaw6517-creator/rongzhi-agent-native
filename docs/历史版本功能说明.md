# 融智 Agent · 企业财务分析与融资组合

用户手工整理并上传年度企业财务数据，系统计算36项指标，识别经营资金占用与偿债风险，再在信用、应收、抵质押、设备融资租赁四个渠道中求解融资组合，输出五个现金流与利率情景及可追溯的分析报告。模型负责理解任务和调度工具；Python负责数值计算、约束求解与报告生成。

当前使用入口是本地 Streamlit 网站 `http://127.0.0.1:8501`。独立 HTML / CSS / JavaScript 前端与 Python API 仍在本地开发，可选启动。公网托管工作已暂停，项目目前没有可供评审直接访问的正式公网链接。

## 启动当前网站

在项目根目录运行；已有虚拟环境时可跳过第一行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

浏览器打开 `http://127.0.0.1:8501`。依赖安装后也可执行 `./start.ps1`。当前界面需要 Streamlit 1.65+，版本约束见 `requirements.txt`。

原生网站的可选本地入口：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-web.txt
./start-native.ps1
```

此入口默认打开 `http://127.0.0.1:8787`，前端位于 `web/`，ASGI入口为 `web_app:app`。这是本地开发版本，不能把本机地址当作参赛链接。

模型配置沿用原项目的 `.env`，没有要求更换原API。支持 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL` / `BASE_URL`、`DEEPSEEK_MODEL` / `MODEL`；配置示例见 `.env.example`。密钥只在后端读取，不要上传或提交 `.env`。没有模型配置也可运行本地计算工作流。

## 数据准备

在“企业与数据”下载中文模板，或直接使用：

- [中文 Excel 模板](data/企业融资分析模板.xlsx)
- [完整模拟示例](data/企业融资分析示例.xlsx)
- [中文 CSV 模板](data/企业融资分析模板.csv)与[模拟 CSV 示例](data/企业融资分析示例.csv)

Excel含“说明、企业财务数据、字段说明、模拟示例”四个工作表。主表为86个中文字段的宽表，每行对应一家企业的一个报告期；模板不要求把未知字段填满。财务数据来自用户核对的资产负债表、利润表、现金流量表和附注，融资条件来自授信文件、债权台账、担保资料、设备采购合同与还款计划。示例企业、数据和报价参数全部为模拟。

要形成有依据的融资组合，除核心报表项目外，重点补充以下内容：

| 输入 | 应确认的口径 |
| --- | --- |
| 报告期及期初、期末余额 | 同一企业、同一合并范围和完整年度；同比数据期间可比 |
| CFADS | 人工核验的可用于偿债现金流；不用净利润代替。缺失时仅在经营现金流与维持性资本支出齐全时提供明确标注的代理桥接 |
| 存量偿债本息 | 自本次分析基准日起未来12个月全部存量有息债务应还本金与应付利息，不是负债余额或历史利息费用 |
| 可投入自有资金 | 扣除受限款及必要经营留存后由人工确认；不从货币资金余额自动推定 |
| 渠道基础金额 | 已获批未使用信用额度、合格债权、未占用担保价值、真实设备采购金额；四个池必须独立可叠加，剔除重复授信和重复资产 |
| 渠道报价与期限 | 各渠道独立年利率、月数、一次性费率及规划折扣；未取得真实机构报价时须保留假设标识 |

金额无单位时按元；表头支持元、万元、亿元。Excel百分比单元格填写`5.2%`或小数`0.052`；中文CSV百分比列和网站编辑栏填写`5.2`，表示5.2%，程序内部统一为0.052。月份为整数，不按金额单位换算。空白表示未知，0表示确认零。未知渠道基础金额不生成容量；未知一次性费率在求解中以0占位，不表示真实免收费。

支持CSV、XLSX、XLSM，单文件最多10MB；可识别中英文表头并合并同企业同期间的数据表。不支持扫描PDF、OCR或直接解析任意版式、科目在行的完整财报。上传后的“字段与金额关系检查”不等于核验报表真实性。

## 使用流程

1. 在“企业与数据”上传填写后的模板，检查识别结果，点击“使用这份企业数据”。也可载入明确标记的模拟案例。
2. 在“分析工作台”确认总资金需求、自有资金、期限、假设利率与用途。综合融资还需填写经营与设备用途子预算，合计等于总需求。结构化字段决定测算，文字说明用于规划。
3. 选择分析重点，按需启用AI，点击“生成融资组合”。启用AI会将当前任务数据发送到原有已配置的模型服务；关闭时仅执行本地工具。
4. 在“财务分析”查看36项指标的公式、来源字段、报告期和缺失原因，以及五维风险与资金占用敏感性。
5. 在“融资组合”查看各渠道分配金额、容量、成本、用途待筹缺口、费用另筹缺口和五个情景。组合预算与单渠道替代方案互斥，不能叠加。原始全额请求的四情景实验另列，不与组合情景混用。
6. 在“分析报告”复核并下载可打印HTML、Markdown、证据JSON及完整ZIP。数据或任务条件改动后重新生成；临时实验不会改写已生成报告。

## 组合求解与公式边界

四渠道线性规划先最大化对外部资金缺口的本金覆盖，再在相同覆盖下最小化输入假设对应的全期限利息与一次性费用。渠道共用一个资金缺口、用途预算与双重压力偿债预算；不会分别测算后直接相加。

- 外部资金缺口=`max(0, 总资金需求−可投入自有资金)`，不是银行核定流动资金贷款额度。
- 组合DSCR=`年度CFADS / (存量未来12个月本息＋各渠道新增未来12个月本息)`。新增部分统一按等额本息比较，月供乘`min(合同月数,12)`；不假设短期到期后续贷。
- 主组合采用CFADS下降20%、新增融资年利率上行1个百分点、压力DSCR目标1.20。三者均是本项目规划假设，不是监管标准、统一银行门槛或获批概率。
- 五情景为基准、CFADS下降20%、利率上行1个百分点、双重压力、额外CFADS下降30%。最后一项用于探索，不参与主组合约束。
- 本金覆盖与另付费用分列；全期限总利息不作为当期一次性筹资缺口。未知费用0占位可能低估真实成本。
- 经营周转指标采用365天；监管流动资金贷款测算示例采用360天，并包含预付、预收及已有周转融资等调整，二者不能混用。

缺失数据不补零；无法计算的指标保留原因。完整年度、CFADS、存量本息或核心字段不足时，不形成肯定组合金额；风险较高时保留的数学结果也仅为待复核条件预算。完整公式、报表口径与政策适用范围见[财务分析与融资组合方法](docs/financial-methodology.md)。

## Agent执行与交付

`task_agent.py`使用原配置模型的Function Calling选择九项工具：`inspect_data`、`calculate_ratios`、`assess_risk`、`retrieve_knowledge`、`simulate_repayment`、`match_routes`、`optimize_financing_portfolio`、`analyze_industry_region`、`prepare_deliverables`。服务端锁定任务数据、限制工具参数和依赖，模型根据观察调整执行顺序。最多10轮规划、16次工具请求，单次模型请求超时35秒。

AI模式按每次任务的分析日期重新研究：行业场景知识库 → 地区/行业/同行三路检索及官方公告目录 → 读取原站正文与发布日期 → DeepSeek按专用JSON提示词提取原文风险信号 → 引用、90天窗口、范围与本企业财务暴露校验 → 知识库规则调整敏感性情景 → 重新运行同一LP → 对照基础组合和市场组合。页面展示来源、日期、研究步骤、触发/拒绝理由、规则版本、证据指纹及金额差异，报告与ZIP保留完整快照。页面切换不重复检索或付费，新任务才刷新市场资料。

无额外密钥可直读央行最近两期LPR、制造业国家统计局PMI目录；地区官方目录当前配置苏州经济运行栏目，其他地区走公开搜索。可在 `.env` 配置 `TAVILY_API_KEY` 启用更广泛的近季度检索（可能产生第三方检索费用），未配置时走尽力而为的公开RSS；不承诺覆盖所有行业/地区或取得同行公告。规则见 `data/market_knowledge.json`，地区目录见 `data/market_source_registry.json`。检索仅发送行业与地区，企业账表只发送到原配置模型服务。

市场不利信号通过正文与时效校验后触发预设压力档位，金额由Python重算；不改写企业已确认渠道容量、填报利率或合同。25%/30%现金流下降及1.5个百分点加息属于敏感性设计，尚未经统计校准；LPR变动不是本企业报价。没有有效新证据或没有触发规则时保持基础金额，不人为制造“每月不同”。没有可比样本时不输出同行平均利率或获批概率。

不启用AI时明确标记为“本地工作流”，行业地区分析标为“未启用”，不调用模型或联网检索；模型中断后保留证据并标记“AI中断·本地续跑”。指标、组合金额和报告数字始终由Python生成。结果追问用于解释已有结果。

交付包包含`report.html`、`report.md`、`evidence.json`、`action-checklist.csv`和`delivery-status.json`。HTML可在浏览器打印另存PDF，证据包含生成时的数据、条件与执行快照，不含API凭据。

## 分层检索与替代分析

AI模式下，地区金融环境、行业经营和同行披露分别检索。优先使用官方直读资料及本地区、细分行业资料；仍不足则依次查询上级地区、大类行业、同省或行业集聚地区候选，最后查询一年内的历史背景。每次最多18条检索、36篇新增正文，保留查询、日期、命中结果、参考层级及适用限制。找到某一路资料不会停止其他路的补充；搜索不可用时仍明确记录缺口。

替代地区是搜索候选，并不自动代表经济水平相近。同行模型提取必须引用连续原句；服务器核验公司名称、行业、地区、期间、用途并从原文提取营业收入。相似分使用项目启发式权重：行业35、地区20、规模25、期间10、用途10。仅当细分行业、当地地区、财务期间、用途一致、营业收入相差不超过一倍且披露处于90天窗口时，标为严格筛选的可比候选；其余仅作机制参考。该分数不是审批概率，不能据此生成行业平均值或银行报价。

大类行业、上级地区、替代地区、历史背景不直接触发企业风险参数。全国LPR仍由专用公告规则处理。报告及页面保留替代范围和检索过程；已有历史快照不会自动更新，需要重新生成AI任务。未配置检索服务密钥时使用免费Bing RSS与官方索引，同行与细分行业覆盖仍受公开资料和检索服务限制。


## 三种分析重点

结果页面分工：融资组合页用于作出选择、核对字段及调整试算；分析报告页使用独立成果摘要，集中说明本次问题、核心结论、按目标挑选的关键指标、主要风险、三项代表压力情景、策略代价与市场证据影响。完整公式、渠道诊断与所有原始情景放入导出报告附录，报告页不重复工作区修改控件。历史任务也可按新摘要结构查看，不改变原始任务金额。

调整试算按分析重点开放不同假设：融资组合调整自有资金和可用信用额度；风险分析调整年度CFADS与已有债务年度本息；方案比较调整现金压力降幅20%至40%及加息1至5个百分点。服务端重新校验数据、计算指标和风险、求解组合，并展示与原方案的差值；不请求模型、不联网、不持久化修改，沿用当前任务市场压力口径。真实采用前须核验依据并更新企业资料、重新生成正式任务。原生网页对应`POST /api/runs/{run_id}/adjustment`，沿用会话归属与请求边界校验，仅接受所选重点的字段。

切换分析重点后需要重新生成任务，结果页和导出报告会优先展示所选重点，基础财务数据保持同一口径。

- 融资组合：先说明自有资金、各渠道借款、用途缺口及全期限假设成本，解释金额分配依据。
- 风险分析：按项目筛查规则排列风险；固定所选组合及加息假设，计算年度还款现金触及覆盖率1.20时的下降临界点，并分别测算通过设定现金压力需要增加的CFADS、或减少的年度本息。这两种改善是替代路径，不可重复计入；临界点不是收入降幅、违约概率或月内安全证明。
- 方案比较：重新求解三种取向——最大覆盖后最小总成本、同样最大覆盖后最小未来12个月加息本息、以及更强现金与利率压力下的组合。统一压力下比较新增借款、缺口、全期限成本与还款；相同渠道分配自动合并，输入无效则不给可行方案。借款金额和期限不同时，不能把总成本直接当年化利率排名。

AI规划与行业地区专项调用均传入所选重点。专项模型读取Python计算的task_focus，不自行修改金额和临界点；提示词要求先用日常语言解释结论、理由和具体行动，再补专业术语。最终专项结果会按已核验市场情景重新计算并保存在交付快照。三类算法假设仍是本项目的规划设置，不等于机构实际授信标准。
