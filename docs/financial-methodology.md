# 财务分析与融资组合方法

本方法对应当前年度企业财务分析与四渠道组合功能。用户负责提供、核对原始数据与融资条件；Python计算指标和求解约束；模型选择、解释工具。结果用于融资准备和条件预算，不替代会计鉴证、银行审查或真实合同测算。静态方法资料核对日期为2026年10月12日；AI新任务另按分析当日检索近期市场资料，覆盖范围与时效校验见第9节，不构成全量政策订阅。

## 1. 数据与报表口径

中文Excel模板有86个字段，以及“说明、企业财务数据、字段说明、模拟示例”四个表；主表每行对应一家企业的一个年度。CSV为同样字段的单表。用户填原始报表项目及经人工确认的融资参数，不需要先算36项指标。

报表字段参考财会〔2019〕6号的一般企业财务报表格式，面向执行企业会计准则的非金融企业。该文件规定报表列报，不规定本项目融资阈值或算法；金融企业、小企业会计准则及特殊行业需另判断适用性。[财政部：2019年度一般企业财务报表格式](https://www.mof.gov.cn/gkml/caizhengwengao/wg201901/wg201905/201909/t20190912_3385305.htm)

| 数据层 | 原始资料与人工核验事项 |
| --- | --- |
| 三张报表及附注 | 企业、合并范围、年度、单位、期初期末及上年可比口径 |
| 现金与债务 | 受限资金、最低经营留存、全部有息债务合同；自分析基准日起未来12个月应还本金与应付利息 |
| CFADS | 可用于偿债现金流及调整明细；覆盖期间、必要经营支出、现金流分类和一次性项目 |
| 渠道基础 | 已批未用授信、应收台账和履约凭证、担保权属占用、设备合同；真实性、适格性及渠道独立性 |
| 渠道参数 | 独立年利率、月数、一次性费率、规划折扣与实际还款结构 |

金额统一为元。Excel百分比单元格填`5.2%`或`0.052`；中文CSV百分比列和网站填`5.2`表示5.2%，内部均为0.052。月份独立输入。缺失不补0；未知渠道基础金额不配置容量；未知一次性费率目前以0占位，真实费用仍未知，可能低估成本。

年度支持`2025`、`2025年`、`2025年度`、`2025-12-31`等标识。中期或期间不明，不自动年化用于年度周转、现金覆盖和组合。字段与金额关系检查不代表报表验真。

## 2. 关键区分与桥接

**现金：** 兼容字段`cash_and_equivalents`表示“货币资金”，可能含受限部分；`cash_equivalents_balance`单列现金流量表现金及现金等价物期末余额，二者不自动互换。非受限货币资金=货币资金−受限资金。可投入自有资金仍由人工确认，不自动等于余额，也不能忽略工资、税费及日常付款留存。

**有息债务：** 短期、长期、一年内到期长期债务三项互斥。短期不含另列一年内到期长期债务，长期剔除已单列的一年内到期部分。三项为期末规模，未来12个月本息为计划现金流，不能互换；一年内到期长期债务也不能替代全部应还本金。

**利润：** 营业利润不当作EBIT。手工EBIT缺失且净利润、所得税费用、利息费用完整时，可按三者之和桥接，保留公式和来源，仍需核对损益口径；“财务费用”总额不能直接作为利息费用。EBITDA=EBIT＋折旧摊销，不是可自由使用的现金流。

**CFADS：** 人工核验输入优先；缺失且经营现金流与维持性资本支出完整时，仅桥接“经营现金流−维持性资本支出”代理，明确标注，不用净利润替代。总资本开支与维持性开支不同；税费已经包含在经营现金流中时，不能无依据重复扣除。用历史代理作下一年规划需说明稳定性及调整假设，不能称为已验证预测。

**存量本息：** 人工确认计划优先；缺失且未来12个月本金、利息两项齐全时才合成。期末债务余额、历史利息费用不能替代还款表。历史年度CFADS与未来本息比较属于规划检验，期间不一致时需人工调整。

## 3. 36项指标

“平均”为同期间期初、期末算术平均。百分比、元、倍数、次数、天数分别显示。缺少来源、分母为0或不满足适用条件时保留无法计算原因。

| 序号 | 指标 | 当前公式或口径 |
| ---: | --- | --- |
| 1 | 流动比率 | 流动资产 / 流动负债 |
| 2 | 速动比率 | 人工确认速动资产 / 流动负债 |
| 3 | 货币资金总额 / 流动负债 | 含受限部分的货币资金 / 流动负债 |
| 4 | 资产负债率 | 负债总额 / 资产总额 |
| 5 | 利息保障倍数 | EBIT / 利息费用 |
| 6 | 总资产收益率 | 净利润 / 平均总资产 |
| 7 | 净资产收益率 | 净利润 / 平均权益 |
| 8 | 净利润率 | 净利润 / 营业收入 |
| 9 | 毛利率 | 毛利 / 营业收入；缺失毛利可由收入−成本桥接 |
| 10 | 应收周转率 | 营业收入 / 平均应收账款 |
| 11 | 应收周转天数 | 平均应收 / 营业收入 × 365 |
| 12 | 存货周转率 | 营业成本 / 平均存货 |
| 13 | 存货周转天数 | 平均存货 / 营业成本 × 365 |
| 14 | 总资产周转率 | 营业收入 / 平均总资产 |
| 15 | 经营现金流 / 净利润 | 经营现金流净额 / 净利润；净利润须为正 |
| 16 | 经营现金流 / 流动负债 | 年度经营现金流净额 / 期末流动负债 |
| 17 | 经营现金流率 | 经营现金流净额 / 营业收入 |
| 18 | 收入增长率 | (本期收入−上期收入) / 上期收入；上期须为正 |
| 19 | 净利润增长率 | (本期净利润−上期净利润) / 上期净利润；上期须为正 |
| 20 | 存量DSCR | CFADS / 存量未来12个月本息，不含拟新增组合 |
| 21 | 利息负担 | 利息费用 / 营业收入，不是借款利率 |
| 22 | 外部资金缺口 | max(0, 总需求−可投入自有资金) |
| 23 | 净营运资本 | 流动资产−流动负债，不等于现金 |
| 24 | 非受限货币资金 | 货币资金−受限资金 |
| 25 | 非受限现金覆盖流动负债 | 非受限货币资金 / 流动负债 |
| 26 | 有息债务合计 | 短期＋长期＋一年内到期长期债务，三项互斥 |
| 27 | 净有息债务 | 有息债务合计−非受限货币资金 |
| 28 | EBITDA | EBIT＋折旧摊销 |
| 29 | 有息债务 / EBITDA | 有息债务合计 / EBITDA；EBITDA须为正 |
| 30 | 营业利润率 | 营业利润 / 营业收入 |
| 31 | 应收逾期占比 | 逾期应收 / 期末应收；按合同到期日核对 |
| 32 | 逾期90天以上应收占比 | 逾期90天以上应收 / 期末应收 |
| 33 | 应付周转天数 | 平均应付 / 营业成本 × 365 |
| 34 | 现金转换周期CCC | 应收天数＋存货天数−应付天数 |
| 35 | 经营现金流扣资本开支 | 经营现金流净额−总资本支出，不等于CFADS |
| 36 | 经营现金流 / 有息债务 | 年度经营现金流净额 / 期末有息债务合计 |

收入近似赊销额、成本近似赊购额，可能不同于含税台账或实际采购流量。CCC不宜对无相关科目的行业直接套用。回款提速15天、存货提速10天的占用敏感性分别按年度收入/365×15、年度成本/365×10估算；尚未发生的改善不算已筹。指标需结合行业、季节性和会计政策判断，无跨行业统一安全线。

## 4. 365天经营分析与360天监管示例

2024年《流动资金贷款管理办法》要求结合真实经营需要与现有资金审慎确定规模。附件示例采用360天，另考虑预付、预收、增长和已有周转融资；项目365天CCC和“总需求−自有资金”不能直接替代银行测算。[国家金融监督管理总局：流动资金贷款管理办法，2024年第2号](https://www.nfra.gov.cn/cn/view/pages/rulesDetail.html?docId=1151066)

模板分别保存营运资金总需求、本次经营用途子预算、现有流动资金贷款、其他营运资金融资等字段；总需求测算需扣除相关已有资金，本次用途子预算则仅是当前项目拆分。当前36指标与LP未自动执行该附件完整测算，填预计收入增长率不等于完成监管核额。360与365应各自保持一致，不能跨公式拼接。

项目保守限制信用和应收用于经营部分、设备租赁用于设备部分；这是产品选择。流贷办法另有特定小额固定资产相关贷款可参照执行的规定，项目限制不能称为所有产品的法律禁令。

## 5. 渠道容量与独立性

| 渠道 | 模型容量 | 实施前核验 |
| --- | --- | --- |
| 信用 | 已批未用独立额度 | 批复、有效期、提款条件、用途、共享总额度及已占用部分 |
| 应收 | 人工确认合格债权 × 规划折扣 | 交易与履约、权属、债务人能力、账龄争议、回款安排、已有转让质押 |
| 抵质押 | 未占用担保价值 × 规划折扣 | 可设权与可处置性、评估和顺位；剔除应收使用同一债权及租赁设备 |
| 设备租赁 | 真实采购金额 × 折扣，受设备子预算限制 | 设备适格性、所有权、价值交付、使用寿命与租金现金流匹配 |

四个池须独立可叠加。共享授信、担保物或债权交叉占用时，当前四独立上限模型不能自动消除关联，需先人工剔除重复；未确认前不能实施。账面资产、全部应收及“可提供担保材料”不会自动生成额度。

应收融资的合同结构、追索权、回款账户及担保安排须按实际机构条款核对；当前统一模型只做资金预算，不代选法律结构。

金规〔2025〕25号要求调查金融租赁物适格性、权属、价值及承租人现金流，并使期限、租金与资产寿命及经营回收匹配。文件2025年12月发布、2026年1月1日起施行，不能概括所有普通租赁。项目采购金额折扣未覆盖完整售后回租估值与合同审查。[金融租赁公司融资租赁业务管理办法，国务院网站转载](https://app.www.gov.cn/govdata/gov/202512/06/540892/article.html)

缺省应收70%、抵质押50%、设备租赁70%折扣可修改，均为规划假设，不是机构质押率或获批承诺。模拟示例独立填写设备折扣80%，经营用途仍不分配设备融资。

## 6. 线性规划与成本

四渠道本金为`x_i`，总需求`N`，可投入自有资金`I`，外部缺口`G=max(0,N−I)`；容量`C_i`、年利率`r_i`、月数`n_i`、一次性费率`f_i`在本次求解中固定。

- `0≤x_i≤C_i`，且`Σx_i≤G`。
- 信用与应收之和不超过经营子预算，设备租赁不超过设备子预算；综合融资两个子预算之和等于`N`，不另加到总需求。
- 四渠道共用双重压力下新增未来12个月本息预算，不重复分配CFADS。

等额本息月供`M_i=x_i×j_i×(1+j_i)^n_i / ((1+j_i)^n_i−1)`，`j_i=r_i/12`；零利率为`x_i/n_i`。新增未来12个月本息=`M_i×min(n_i,12)`，短合同只算实际期数，不假定续贷。保理回款、到期还本、不均匀租金及提款计划需按真实合同另测。

非负年度CFADS为`F`，存量未来12个月本息为`D`。双重压力用`0.8F`及新增利率`r_i+0.01`，新增本息预算=`max(0,0.8F/1.20−D)`。负CFADS不配置新增债务；存量已不能满足目标时，新增预算0不表示整体偿债安全。

算法枚举四变量可行域顶点，先最大化`Σx_i`，再在同覆盖额下最小化`Σ(M_i×n_i−x_i＋f_i×x_i)`。第二目标为全期限假设利息加一次性费，不是年化综合利率、IRR或折现成本。本金按分保守取整，约束允许时补充分币余量。

一次性费用在用途本金之外另筹；自有资金超出原用途需求的余额可抵费用，其余单列费用缺口。用途缺口与费用缺口分别列出并汇总；全期限利息不直接算当期一次性筹资缺口。保证金、保险评估、残值、税费及提前还款等真实合同支出尚未全面建模。

最优仅限本次四候选与输入条件，不是全市场最低成本或银行核定额度。无真实报价时只能比较假设；未知费率0占位可能改变排序与实际净额。

## 7. 五情景与原始请求

| 情景 | CFADS变化 | 新增利率变化 | 用途 |
| --- | ---: | ---: | --- |
| 基准 | 0 | 0 | 原假设覆盖 |
| 现金流压力 | −20% | 0 | 现金流下行 |
| 利率压力 | 0 | ＋1个百分点 | 新增融资利率上升 |
| 双重压力 | −20% | ＋1个百分点 | 主组合共享约束 |
| 额外探索 | −30% | 0 | 不参与主求解 |

同一组合的整体DSCR=`情景CFADS / (存量未来12个月本息＋组合新增未来12个月本息)`。存量本息保持输入值，未对存量浮息合同重新定价；负CFADS压力按恶化方向增加负值幅度。分母0不显示无限大。年度现金缺额=`max(0,1.20×情景总本息−情景CFADS)`，是达到目标所缺CFADS，不是贷款本金或营收预测。

DSCR1.20、CFADS下降20%、利率上行1个百分点均为项目假设，非监管标准、统一银行门槛或统计预测；额外30%下行用于显示脆弱性，不能掩盖不达目标情景。

原始全额请求另按完整`G`和统一任务利率、期限测四情景；组合按各渠道金额与独立参数测五情景，两组不能混用。单渠道对照替代组合，不能相加；期限和覆盖不同的总成本不能当作同金额年化排名。

## 8. 证据与实施边界

指标保留公式、来源、期间与缺失原因；组合保留参数、容量、约束、情景、成本、缺口和建议。任务绑定当时数据与需求快照；修改后重算，旧快照无组合时提示重新生成，不补造结果。

数据矛盾或不足不形成肯定融资金额；较高风险时数学预算仍待人工整改复核。组合、替代方案、敏感性和待落实缺口都不是已筹资金，材料勾选也不等于机构审批。

行业、地区、年限用于核验提示，不能凭“科技型企业”标签推断授信、补贴或政策资格。规则未做行业实证校准，轻资产、金融、工程及季节性企业需另核对适用性。

当前没有真实银行报价产品库、征信或交易验真，也没有月度收支、实际还款日、季节性、续贷不确定性和多年度滚动模型。年度DSCR达标不保证每月能付，设备折扣不完成租赁尽调，债权输入不完成确权。正式融资仍需确认机构条件、合同现金流、用途及数据授权。


## 9. 行业与地区模型分析

启用AI后，先计算并锁定基础融资组合，再执行行业地区研究。研究计划由行业知识库扩展关键词，检索地区金融环境、行业经营与同行融资披露。另直读央行LPR目录和制造业PMI目录；地区官方目录目前包含苏州经济运行，其他地区使用公开搜索。可选Tavily接口使用近季度过滤；未配置时公开RSS尽力检索，不把检索无结果当作环境平稳。

原站只允许政府、交易所及指定披露域名HTTPS，逐跳校验跳转与公网DNS，限时限流并限制正文大小。不访问模型生成的URL。发布日期来自页面元数据、公告标题的完整日期或明确发布时间标签；不凭URL猜日期。PDF及无法取得正文的条目不触发数值调整。分析基准为Asia/Shanghai日期；未来、未知日期及90天外资料可以提供历史背景，不能触发近期规则。
