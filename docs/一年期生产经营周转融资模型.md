# 一年期生产经营周转融资

原生网站固定规划期12个月、用途生产经营周转。输入为三个连续完整年度，模板按最新年度、上一年度、上两年度排列，年份由上传者填写。只预测最新财报年度的下一年；较旧财报对应的是历史规划年度，不能冒充当前年度判断。财务数据通过模板上传。

## 财务诊断

五块：资产负债、应收与固定资产、营运资金、现金流、盈利归因。依据包括Nissim–Penman结构分析、Shapley杜邦代数分解、营运资金研究及现金流量表恒等关系，详见[方法依据](诊断决策风险方法与依据.md)。只呈现结论及必要数据，不把利润增长直接变成授信增加。

## 一次历史检验与校正

以前两年预测第三年，第三年实际值仅作历史误差检验。预测采用两年CFO/收入比例均值乘预计收入，收入增长默认延续同比并限在−30%至50%。下一年原始预测使用最近两年数据。

历史有符号误差e＝历史预测−实际；下一年校正额Δ＝clip(−0.5e, −b, b)，b＝0.3×max(|下一年原始预测|, |最新实际CFO|)。原始预测非正时，不允许通过正校正把它变成正现金。校正预测＝原始预测＋Δ。0.5与0.3是显式收缩、限幅假设，不是训练所得或论文建议的最优参数；一个残差不能证明校正必然更准确。页面同时保留校正前后值与规则。

## 产品与期限

信用流动资金贷款、抵押流动资金贷款、应收账款质押流动资金贷款，三类均按12个月合同假设。移除设备租赁。采用应收质押而非半年保理，避免低成本短期产品被误解为能覆盖全年需求，不自动假设债权替换或贷款续作。

- [流动资金贷款管理办法](https://credit.mot.gov.cn/zhengcefagui/202408/t20240807_4147083.html)：支持日常生产经营周转的用途边界；一年是本系统自选范围，并非法规最长贷款期限。
- [建设银行应收账款融资](https://wealth2.ccb.com/cn/home/company/gsyw/560037.html)：真实应收质押业务依据；银行审核、回款账户、债权账期及担保覆盖仍须确认。12个月不等于每笔应收账款可无条件抵押12个月。
- [2026年9月LPR公开资料](https://jrj.wuhan.gov.cn/ynzx_57/xwzx/202609/t20260921_2851618.shtml)：一年期LPR 3.0%。默认参考贷款年利率4.0%＝该参考＋1个百分点。加点、产品利差、费用、资产融资比例为演示假设，允许替换，不冒充实时银行报价或回溯规划年度的历史报价。

## 决策模型

混合整数规划，连续变量为产品本金，二元变量为产品启用。第一阶段最大化净到账（本金减比例、固定费用），不超过用户净需求。第二阶段在覆盖金额容差0.1元内最小化“全期利息与费用＋0.1×情景CVaR80%”。只输出一套推荐组合，不再默认比较三种风险权重。

约束：产品资产/收入池、固定12个月用途、资产负债率、压力现金偿债安全线、全年生产经营用款上限。经营用款上限采用预计营业成本，是宽松的用途规模检查，不是内部预算、真实营运资金缺口或银行授信测算。已到期短债与一年内到期部分加历史/假设利息形成旧债服务代理；不再把全部长期借款机械分三年归还。

年内支付时点另用全年现金均分作敏感性检查，明确不是逐月经营现金预测。缺少真实合同与季节性，不能据此证明每个月都能还款。

## 六个确定性风险情景

1. 基准：校正CFO减维持性投资。
2. 现金承压：还款现金默认下降20%，可调整，是敏感性假设。
3. 回款延迟：延迟天数=max(5天，三年最慢应收天数−最新值)，最高30天；现金减少=预计收入/365×天数。5/30是测试边界。
4. 毛利下降：采用三年毛利率极差，限1—5个百分点；现金减少=预计收入×降幅，假设全额现金影响，不计税盾。
5. 加息：新增融资利率默认上升1个百分点，现金不变；实际固定利率可据合同重新评估。
6. 联合：最紧现金情景与加息共同测试；若原有历史利润/周转联合情景更严，采用该现金值并列明具体历史参数。

使用六情景最紧还款现金与加息约束优化，同一组合接受情景检查，显示本息、覆盖倍数、距离安全线的现金缺口及逆向现金下降边界。不提供违约概率或蒙特卡洛频率。另用CVaR80%汇总既有六个等权情景的尾部现金余量损失：L_s=max(0，基准偿债后余量－情景偿债后余量)。它衡量余量下降，不是现金不足，避免与硬偿付约束重复为零。采用Rockafellar–Uryasev线性化，alpha=0.8、权重lambda=0.1和等权分布都是显式设计假设。六情景最差20%权重按分数尾部平均；推荐结构相近时结果可能不变。参考[BCBS压力测试原则](https://www.bis.org/committees/bcbs/basel-consolidated-guidelines/module/rma/30)的相关性、合理性与透明性要求；没有把20%、1个百分点等宣称为业界统一数值。

模型参数包括1.2倍安全线、65%负债率上限等，均是明确可调假设。对话只能调整金额与允许的参数；固定一年期限和生产经营周转用途由服务端验证。
