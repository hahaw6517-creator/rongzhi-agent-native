# 海天味业三年真实算例

海天味业案例采用海天味业（603288.SH）的2023—2025年度合并财报，原始取数为人民币元，页面及上传工作簿展示金额为亿元。
每年34项核心科目和4项公开附注均有取数记录；数据、逐项页码与原文链接保存在 `data/real_case_haitian.json`。

2024、2025年采用公司官网2025年年度报告第86—95、154、156、160、174页；2023年采用巨潮资讯2024年年度报告上期比较列第76—87、152、154、172页。

- [2025年年报](https://static.haday.com/upload/2026/03/27/e862e415c60546c899815c5a61da233f.pdf)
- [2024年年报](https://static.cninfo.com.cn/finalpage/2025-04-03/1222994233.PDF)

2025年年报重述了2024年比较数据，故不使用结构化缓存的2024年原始披露数。2023年尚未取得同一合并范围的重编完整三表，保留2024年年报所列真实比较数据，不自行拼造重述数。2023→2024年的动态变化包含合并口径影响，不能完全归因于经营改善。2024→2025年使用同份年报的比较口径。

预收款项为零有附注37“不适用”支持；2025年长期借款非流动部分为零由附注45确认：1500万元借款全部转入一年内到期部分。其他缺失不作补零。净利润采用合并净利润，不用归母净利润替代。

## 演示融资需求（假设）

演示统一采用外部净融资3亿元、12个月、生产经营周转，便于比较不同财务结构下的渠道配置与约束。该需求为演示假设，不是企业公告中的实际融资申请，也不能据此认定企业有3亿元真实资金缺口。

候选为信用、抵押、应收账款质押三类流动资金贷款。海天味业现金较充足，案例用于说明融资需求、融资成本与现金安全之间的权衡，不能把系统的融资需求检查描述为必须借款。

利率、手续费、资产融资比例继续使用可编辑的模型假设，不冒充该企业实际可取得的银行报价。案例财报不会因融资需求调整而改写。

## 使用

进入“企业与数据”，选择“载入真实算例”，载入三期财报后在分析工作台核对融资需求，再执行分析。载入案例会替换当前编辑企业，已生成报告与临时方案的适用企业需要分别核对。

页面可下载与内置数值一致的Excel；上传模板的三个年度由用户填写。真实算例固定2023—2025年，未来年份不自动改标签。

## 其他公开企业数据

金山办公、宁沪高速的数据及逐项来源位于 `data/official_cases/`，对应 Excel 位于 `output/真实企业案例/已验证演示/`。相同需求下的融资配置会受企业现金、杠杆及产品容量影响，也可能没有通过验证的新增债务方案；这不是银行拒贷结论。

福耀玻璃、中国中免 Excel 位于 `output/真实企业案例/未运行测试/`，仅提供用户自行上传测试，没有提前执行其融资决策或风险分析。报表真实值与模型需求、利率等假设分别管理。
