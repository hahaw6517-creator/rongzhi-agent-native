# 海天味业三年真实算例

内置案例采用海天味业（603288.SH）的2023—2025年度合并财报，人民币元。
每年34项核心科目和4项公开附注均有取数记录；数据、逐项页码与原文链接保存在 `data/real_case_haitian.json`。

2024、2025年采用公司官网2025年年度报告第86—95、154、156、160、174页；2023年采用巨潮资讯2024年年度报告上期比较列第76—87、152、154、172页。

- [2025年年报](https://static.haday.com/upload/2026/03/27/e862e415c60546c899815c5a61da233f.pdf)
- [2024年年报](https://static.cninfo.com.cn/finalpage/2025-04-03/1222994233.PDF)

2025年年报重述了2024年比较数据，故不使用结构化缓存的2024年原始披露数。2023年尚未取得同一合并范围的重编完整三表，保留2024年年报所列真实比较数据，不自行拼造重述数。2023→2024年的动态变化包含合并口径影响，不能完全归因于经营改善。2024→2025年使用同份年报的比较口径。

预收款项为零有附注37“不适用”支持；2025年长期借款非流动部分为零由附注45确认：1500万元借款全部转入一年内到期部分。其他缺失不作补零。净利润采用合并净利润，不用归母净利润替代。

## 演示融资需求（假设）

外部净融资3亿元，用于设备更新，期限36个月。金额约占最新年购建长期资产现金支出12.84亿元的23.4%，约占营业收入的1.04%，作为设备项目部分债务资金的测试规模。36个月是中期设备用途测试期限，不是财报披露的实际贷款期限，也不是资产使用寿命估计。

公司现金充足，该情景用于比较保留流动性与新增融资成本，以及抵押贷款、设备租赁等工具的还款差异。它不代表实际融资申请，不能据此认定公司存在3亿元资金缺口。应同时检查“不新增借款或分期投资”的可能性；系统的融资需求合理性检查不应被描述为必须融资。

利率、手续费、资产融资比例继续使用可编辑的模型假设，不冒充该企业实际可取得的银行报价。案例财报不会因融资需求调整而改写。

## 使用

进入“企业与数据”，选择“载入真实算例”，即可同时载入三期财报及对应需求。原有上传数据与已生成报告不会被后台自动覆盖，载入前会说明替换当前编辑数据。已有报告保留为历史记录。

页面可下载与内置数值一致的Excel；空白模板继续按当前年份滚动。真实算例固定2023—2025年，未来年份不自动改标签。
