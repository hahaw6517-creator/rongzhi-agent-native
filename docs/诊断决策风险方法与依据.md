# 诊断、决策与风险方法依据

## 数据与适用范围

用户上传同一企业连续三个完整年度的财务报表原值，并标明年份、币种、金额单位和企业信息。必要项目按当前模板核验；未知不能填零，明确披露为零或不适用才可填零。缺少必要明细时提示补全，不由大模型生成财报数值。

适用于一般非金融企业的一年期生产经营周转分析。三年公开报表不能确定真实授信、担保物估值、合格债权、合同还款计划或月内季节性。

## 财务诊断依据

| 方法 | 理论参考 | 实际应用与边界 |
| --- | --- | --- |
| 资产负债及财务结构 | [Nissim & Penman (2001)](https://www.columbia.edu/~dn75/Ratio_analysis_and_equity_valuation_From_research_to_practice.pdf) | 分析经营、盈利与杠杆，规则阈值不等于授信标准 |
| 盈利归因 | 杜邦恒等式、[Shapley (1953)](https://doi.org/10.1515/9781400881970-018) | 净利率、资产周转与权益乘数的六种替换顺序平均，代数贡献闭合，不是因果识别 |
| 利润变化桥 | 会计利润收支恒等式 | 解释收入、成本、期间费用和税费变化，其他损益保留为剩余项，不强行归因 |
| 多年度信息设计 | [Binz、Schipper & Standridge (2025)](https://doi.org/10.1016/j.jacceco.2025.101805) | 参考细分项目与历史信息的分析思路，未训练或复现论文机器学习模型 |
| 营运资金及周转 | [Jaworski & Czerwonka (2024)](https://doi.org/10.1007/s40622-023-00372-x) | 解释应收、存货、预付、应付、预收及合同负债占用变化；研究不提供统一最优周转天数 |
| 现金流勾稽 | [IAS 7](https://www.ifrs.org/issued-standards/list-of-standards/ias-7-statement-of-cash-flows/)及现金收支恒等关系 | 核对期初、三类净现金、汇率影响与期末；余额变化不是完整间接法调整 |

诊断分五块展示结论及必要证据：资产负债、应收与固定资产、营运资金、现金流、盈利归因。回款提前若干天对应资金占用敏感性，不等于已落实回款。利润增长不能直接换算更高融资额度。

## 现金预测及融资约束

以前两个年度预测第三年，取得一次误差；使用最近两年现金转化和收入情景预测下一年，再作有限误差校正。默认误差转移比例50%、校正限幅30%是显式设计假设，非论文最优参数，单次检验不能证明提高预测精度。

基准预计经营现金扣除维持性投资假设，形成可用于偿债的现金。财报诊断中的利润率及周转变化支撑压力情景，再与用户现金下降及加息设定共同形成偿债约束。杠杆约束使用财报资产与负债；产品容量分别参考收入、固定资产、应收账款；用途规模以预计营业成本作代理检查。

## 组合优化

Python 混合整数规划先最大覆盖扣费后净需求，再最小化一年利息费用与加权情景 CVaR。采用 [Rockafellar–Uryasev 的 CVaR 线性化](https://uryasev.github.io/publications/)。置信水平80%、权重0.1、六情景等权及融资折算比例均为可调假设，理论参考不为这些具体数值背书。

信用、抵押、应收账款质押三类贷款受产品启用、容量、固定期限用途、杠杆、压力偿债及经营规模约束。独立验证复核资金闭合、本息、现金储备和支付时点敏感性；规则池上限不是银行批复额度。

## 风险评估

风险集中于经营现金减少、回款延迟、毛利率下降、利率上升、联合压力及存量债务占用。固定组合接受六个确定性情景检查，并求逆向压力边界。年内现金均分用于支付时点敏感性，不是月度现金预测。

CVaR 的损失定义为相对基准的偿债后现金余量下降；六等权情景最差20%按分数尾部加权。该值不是贷款本金损失、现金不足额或真实违约概率，是否能还款另看安全线缺口与现金储备。

压力测试参考 [BCBS (2018)](https://www.bis.org/bcbs/publ/d450.pdf)关于相关性、透明性和合理情景的原则，不声称获得监管认证。默认现金下降20%、加息1个百分点、安全线1.2倍和负债率65%是演示及敏感性设定，不是业界统一标准。具体情景见 [一年期模型](一年期生产经营周转融资模型.md)。
