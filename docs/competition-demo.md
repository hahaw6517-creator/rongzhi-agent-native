# 融智 Agent 参赛演示指南

建议用一个完整企业案例讲清“上传财务数据—分析资金占用—计算组合—压力检验—导出报告”。核心问题是：企业需要300万元，投入自有资金50万元后，还能借多少、从哪些渠道借、为什么仍有缺口。

本指南按当前本地Streamlit入口`http://127.0.0.1:8501`编写。原生网站仍为本地开发版本，公网托管已暂停；本机地址不是评审可访问链接。以下约6分钟仅为剪辑建议，实际视频时长和提交要求需对照主办方最新通知，本指南不作比赛规则核验结论。

## 录制前准备

1. 在“企业与数据”下载“完整模拟示例”，或使用项目中的`data/企业融资分析示例.xlsx`。保留“模拟”企业名称与数据标识。
2. 打开Excel，展示四个工作表：“说明、企业财务数据、字段说明、模拟示例”。主表有86个中文字段；说明表不作为企业记录。
3. 准备空白模板，说明实际使用时应从原始资产负债表、利润表、现金流量表及附注填报，另核对未来12个月还本付息、CFADS和融资渠道条件。未知留空，确认零才填0。Excel百分比填`5.2%`或`0.052`；CSV百分比列和网站填`5.2`表示5.2%。
4. 需要展示AI自主规划时使用原有配置API；连接失败后如实展示“AI中断·本地续跑”，不要把本地模式说成AI自主执行。录制前自行完成当前页面、模型调用与下载检查。
5. 录制只展示模拟资料，避开密钥、`.env`及私人文件。保留已导出的HTML报告用于展示。

## 本次示例输入

上传模拟示例后点击“使用这份企业数据”，在“分析工作台”确认需求300万元、自有资金50万元、经营周转、默认期限24个月。渠道独立参数以模板为准，默认任务期限不会覆盖已填写的渠道期限。

| 输入 | 模拟值 | 演示时的解释 |
| --- | --- | --- |
| 年度CFADS / 存量未来12个月本息 | 280万元 / 60万元 | 已人工设定的示例口径，不用净利润替代CFADS |
| 已确认未使用信用额度 | 100万元 | 实际使用需核对获批、有效期、提款条件及未占用情况 |
| 合格应收 / 规划折扣 | 180万元 / 70% | 渠道容量126万元；账面全部应收不能自动成为可融资债权 |
| 未占用担保价值 / 规划折扣 | 200万元 / 50% | 渠道容量100万元；须剔除与应收融资重复的债权和已占用资产 |
| 信用参数 | 5.2%，24个月，一次性费率0.5% | 用户规划假设，无真实银行报价支持 |
| 应收参数 | 4.8%，12个月，一次性费率0.8% | 保持12个月，不为提高覆盖人为延长期限 |
| 抵质押参数 | 5.0%，36个月，一次性费率1.0% | 模拟年利率与期限，不表示机构承诺 |
| 设备融资租赁 | 本次配置0 | 当前为经营周转用途，没有设备采购需求 |

四个渠道基础池须独立可叠加；共享总授信、同一笔应收、同一设备不能重复计入不同池。示例基础金额、折扣及报价均为假设，不能称为已核验的真实业务。

## 预期组合与合理缺口

以下为未改动模拟模板的参考结果；页面与报告应来自实际本轮运行，显示金额可能按万元四舍五入。

| 资金组成 | 参考金额 |
| --- | ---: |
| 可投入自有资金 | 50.00万元 |
| 信用融资预算 | 100.00万元 |
| 应收融资预算 | 35.734808万元 |
| 抵质押融资预算 | 100.00万元 |
| 设备融资租赁预算 | 0.00万元 |
| 新增债务预算合计 | 235.734808万元 |
| 用途待筹缺口 | 14.265192万元 |
| 一次性费用另筹缺口 | 1.785878万元 |
| 含费用总待落实缺口 | 16.051070万元 |

渠道容量之和超过250万元外部缺口，压力偿债预算仍限制实际配置。35.73万元应收融资是求解结果，不能为凑满缺口改成126万元。所有融资金额为条件预算；单渠道对照是替代方案，不能与当前组合累加。

可这样说明：“当前压力余量下新增债务约235.73万元。剩余用途支出约14.27万元应延后或缩减，或落实同额股东投入与真实经营回款；手续费另筹。任何新增债务都必须放回同一模型重算。”

## 五情景展示

情景采用同一组合，固定已填报存量本息；利率冲击作用于新增渠道，不表示已对全部存量浮息债务重新定价。

| 情景 | 参考整体DSCR | 讲解重点 |
| --- | ---: | --- |
| 基准 | 1.510 | 输入假设下的未来12个月本息覆盖 |
| CFADS下降20% | 1.208 | 不自动等同于营收下降20% |
| 新增利率上行1个百分点 | 1.500 | 例如5.2%变为6.2% |
| 双重压力 | 1.200 | 主组合规划约束，仍需审查真实合同 |
| 额外CFADS下降30% | 1.057 | 探索情景，不参与主约束；展示现金改善要求 |

“达到目标还需现金”是达到DSCR目标所缺年度CFADS，不是新的贷款额度，不能加到融资本金或已筹资金。组合使用各渠道独立参数；“原始全额请求”四情景实验使用完整外部缺口和统一任务假设，是另一组比较结果。

## 可选的异常演示

载入“信息不全”模拟案例，展示无法计算的原因与补资料任务。也可在示例副本清空某渠道已确认基础金额后重算，说明未知容量不从账面资产推断。清空手工CFADS但保留完整经营现金流和维持性资本支出时，会生成已标注的代理桥接，不构成CFADS完全缺失案例。

改为设备购置用途后，只有真实采购金额、用途预算与独立担保基础已填妥时，才展示设备方案；不要仅切换用途就声称自动获得租赁融资。
