# 公开财务报表金融决策 Agent

用户只提交非金融企业完整年度公开报表原值：资产负债表、利润表、现金流量表，以及可选公开附注。企业名称、报告期、行业、地区、报告链接或名称同样来自公开披露。模板不包含授信额度、合格可融资应收、无负担担保物估值、内部预算、未来合同还款计划或手填CFADS。

这是一套公开数据情景决策模型。模型推导资金需求，不等于掌握企业真实投资计划；借款预算不等于银行已批额度。所有输入区分为公开事实、公式计算和情景假设，缺失不补零，来源可追溯至工作表、单元格和用户填报的公开页码。

## 输入与填表

下载“公开财务报表模板.xlsx”。科目纵向排列，本期、上期金额分列；金额可选元、万元或亿元。只抄公开报告原值，不需自行计算毛利、营运资本、融资缺口或CFADS。预收款项和合同负债分别填写，折旧和摊销分别填写；程序处理加总。没有公开披露时留空，仅在完整公开报表能确认该科目为零时填0。附注为可选，不要求内部明细。源表为PDF时目前需把公开原值录入模板，本版不声称实现扫描PDF识别。

完整金额求解需要基本资产负债、现金流、资本开支、借款余额，以及两期经营性营运资本组成项目。上期收入缺失时使用明确标识的0%增长情景。利息未公开时使用余额乘情景利率作压力代理。资料不足仍计算可得指标，暂停缺乏基础的需求与借款金额，不编造数据。

## 专业计算模型

1. 财务指标模型：流动比率、速动比率、资产负债率、毛利率、净利率、资产与权益收益率、应收和存货周转、现金转换周期、经营现金转换等。缺少分母或期间口径不合格时，显示未计算原因。真实合同DSCR缺少公开输入时不计算；代理覆盖倍数另外列示。
2. 现金需求模型：经营性净营运资本 = 应收＋存货＋预付款－应付－预收－合同负债。历史变动 = 本期值－上期值。变动前经营现金代理 = 历史经营现金流＋历史营运资本增加额。下一年度经营现金情景 = 变动前现金代理×(1＋增长情景)－本期净营运资本×增长情景。该外推将存量周转和增长占款联系起来，但不能消除现金流分类、合并变动与季节性误差。
3. 现金用途与来源：资本开支情景 = 历史购建长期资产现金×资本开支倍数。已有本金到期压力代理 = 短期借款＋一年内到期非流动负债；利息压力来自公开历史利息或显式利率假设。用途 = 资本开支＋已有本息代理＋经营现金赤字；来源 = 正经营现金情景＋历史现金及现金等价物扣留存后的余量。外部缺口 = max(0,用途－来源)。这是情景资金缺口，不是监管核定流贷额度。
4. 现金可承债模型：年度还款现金代理 = 经营现金情景－资本开支情景×维持性占比。现金留存天数、维持性占比和资本开支倍数均是情景参数，不来自企业内部消息。现金及现金等价物不能无条件与货币资金视为同一科目。
5. 约束优化模型：四个决策变量分别为12、24、36、60个月的等额本息借款预算。先最大覆盖缺口，再按策略最小化全期限假设利息或下一年度加息本息。共同约束包括缺口、现金压力可承受本息、情景杠杆和用途期限匹配。短期限不能自动填满投资用途；60个月预算不超过投资剩余缺口。使用四变量线性规划顶点枚举与可行性检查，保留约束系数、解和余量。
6. 杠杆预算：在借款所得暂留资产端的情景下，新增债务不超过 max(0,(杠杆上限×资产－负债)/(1－杠杆上限))。不假定未知授信或抵押物容量，不把该预算称为真实可贷额度。
7. 风险验证：以另一段计算逻辑独立复算月供及下一年度本息，并检查非负金额、本金明细加总、用途匹配、现金压力、杠杆边界和资金闭合。即使新借款为0，现有债务压力未通过也必须显示“未通过”，不能以求解器返回零向量声称整体安全。

未建模真实审批、产品费率、税盾、资金到账时点或月度季节性。默认利率是显式情景假设；费用未纳入，不代表实际免费。公众不能从报表得知未来还款日程，因此不把年度代理覆盖率写成真实合同DSCR。

## Agent闭环与持续交互

公开模式提供11个可调用工具：校验数据、计算指标、自主推导融资需求、风险筛查、检索专业知识、偿付测算、期限结构准备、优化组合、行业地区近期研究、独立验证、交付报告。启用原配置DeepSeek接口后，模型根据工具依赖选择执行并观察结果；金额由Python模型生成，大模型不能直接写入财务值或绕过验证。关闭AI时执行同一工具图，明确标识本地模式。

行业地区模块沿用原有来源检索、正文与日期核验、资料降级参考和规则触发重算。已有更强压力假设不会因检索结果被自动调低。新版本重算沿用已保存的公开来源时，重新核验其时效与适用性，明确说明未新检索、未新调用模型，不把历史解释伪装成新分析。

三个分析重点分别突出资金与期限安排、现金风险临界点与改善措施、不同策略的取舍。用户修改情景后重新推导需求、求解、验证并保存版本，记录父版本和金额差异，原始报表及旧报告不变。原值已修改时，应先用新报表生成任务，避免用历史报告静默覆盖新数据。

## 公开方法参考

- [国家金融监督管理总局《流动资金贷款管理办法》及需求测算示例](https://www.nfra.gov.cn/cn/view/pages/rulesDetail.html?docId=1151066)：要求结合经营规模和资金循环测算需求，实际授信还需其他资料。本项目没有必要私有数据，因此不宣称复现了银行完整核贷流程。
- [证监会《监管规则适用指引——会计类第1号》](https://www.csrc.gov.cn/csrc/c100038/c1570917/content.shtml)：经营、投资与筹资现金流分类必须区分。项目的现金外推仅为情景代理，分类差异会影响结果。

模型阈值与参数是本项目设置，未做行业实证校准；数学通过不是对现金预测准确性、违约概率或审批结果的证明。
