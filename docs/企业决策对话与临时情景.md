# 企业决策对话与临时情景

对话默认携带当前企业原始财报、已计算指标、财务诊断、现金预测、融资组合、风险与验证记录及已检索市场证据。固定专业角色和本地知识库在每轮注入；这是应用提供上下文，不是修改或训练DeepSeek模型权重。API配置沿用原设置。

当前企业的近期对话、明确表达的回答偏好、最近融资边界和至多六个临时情景保存在本地SQLite。切换企业名称或报告期时清除活动分析和继承的需求；专业知识库保留。旧分析作为历史快照保存，不能继续当作新企业事实。企业原值或正式参数变化后，旧情景不能直接采用。

一般解释不强制调用修改工具；数值和引用仍须核验。边界工具解除本次小额需求限制，保持用途、产品规则、杠杆和现金约束，分别求解期限边界。临时情景由Python重新执行财务分析、MILP/CVaR优化、风险测试及验证，默认不创建正式版本。可比较成本优先、均衡和偿付优先三种已封装策略，不能凭对话执行任意代码。

融资需求和模型参数情景可通过服务器保存的情景ID提出采用，确认后才更新四个模块。对历史收入、净利润或经营现金流的假设变化仅用于敏感性探索，不能将假设写成真实财报。真实科目纠错仍需明确金额与单位并确认。模型调用失败、参数含糊或验证未通过时保留原报告。

报告和对话使用更宽布局；对话独立滚动、按可见高度调整，并支持展开查看。发送和刷新对话时保留页面位置。市场证据只有经过新检索和来源核验才可称近期信息；融资边界是条件式模型结果，不是银行审批额度。
