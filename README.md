# 融智 Agent · 企业财务分析与融资决策

面向一般非金融企业的原生网站。上传连续三年财务报表数据，提供外部净融资需求，完成财务分析、融资组合决策、风险检验与报告交付。规划期限固定为 **12个月**，资金用途固定为 **生产经营周转**。

**部署入口：`web_app.py`。运行依赖：`requirements-web.txt`。容器部署：使用根目录 `Dockerfile`。**

## 功能流程

分析工作台 → 企业与数据 → 财务分析 → 融资决策 → 风险评估 → 分析报告。

- **数据导入**：用户填写最新年度、上一年度、上两年度的年份及报表原值，金额展示统一为亿元；缺失数据不能以零代替。
- **财务分析**：计算指标，分块解释资产负债、应收与固定资产、营运资金、现金流和盈利变化。以前两年数据检验第三年现金预测误差，再对下一年预测作有限校正。
- **融资决策**：筛选信用、抵押、应收账款质押三类流动资金贷款。Python 混合整数规划先尽量覆盖净需求，再权衡一年成本与情景 CVaR，受现金、杠杆、产品容量及经营用途约束。
- **风险评估**：对固定组合检查六个明确情景，展示偿债安全线、缺口、逆向压力边界及 CVaR80% 的现金余量下降含义。
- **分析报告**：提炼财务结论、融资策略、风险与行动，下载 Word；专业对话携带本企业数据及分析背景，支持融资上限查询、多参数临时重算，采用前不改变正式结果。

DeepSeek 负责理解需求、选择工具和解释结果，数值由 Python 模型计算。关闭 AI 仍可运行本地分析；行业地区资料只有经过检索核验才能作为近期证据。预测、融资比例、利率与压力参数含明确假设，结果不等于银行授信或未来现金承诺。

## 本地启动（Windows）

已有 Python 环境时，在项目根目录打开 PowerShell，执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start-native.ps1
```

浏览器打开 `http://127.0.0.1:8787/`。首次安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-web.txt
```

## 云端部署

建议 Python 3.12。在仓库根目录安装并启动：

```sh
python -m pip install -r requirements-web.txt
HOST=0.0.0.0 PORT=8000 python web_app.py
```

平台分配端口时使用平台的 `PORT`。支持 Docker 的平台直接选择根目录 `Dockerfile`，容器启动同一个原生入口。

通过平台环境变量配置 `DEEPSEEK_API_KEY`、`BASE_URL`、`MODEL`，可选配置 `TAVILY_API_KEY`。变量示例见 `.env.example`；实际密钥不上传 GitHub。

数据库通过 `FINBRIDGE_DB_PATH` 指定。容器默认使用 `/app/storage/runtime.sqlite3`，需要保留分析和对话时，将持久化磁盘挂载到 `/app/storage` 并另做备份。持久化存储不等于已经备份。
