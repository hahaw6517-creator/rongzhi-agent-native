# 融智 Agent：企业财务与融资决策

当前原生网站：分析工作台 → 企业与数据 → 财务分析 → 融资决策 → 风险评估 → 分析报告。适用于一般非金融企业完整年度财报，不限定中小微或科创行业。新仓库为独立原生版本，不关联此前的 Streamlit 部署；交接请先阅读 [原生网站部署说明](docs/原生网站部署交接.md)。

上传连续三年财报 Excel（最新年度、上一年度、上两年度，由用户标明年份），另提供外部净融资需求。当前固定12个月、生产经营周转用途。Python负责指标、分块财务诊断、一次历史预测误差校验与下一年现金情景、融资产品筛选、先最大覆盖需求再权衡成本与情景CVaR的优化、明确情景压力测试和独立验证。当前一年期主流程不以蒙特卡洛生成违约概率。DeepSeek理解需求、选择工具和解释结果。报告右侧对话支持参数临时重算，用户选择采用后才更新正式分析，报告以Word下载。

启动：运行 start-native.ps1，打开 http://127.0.0.1:8787/ 。依赖见 requirements-web.txt，API继续使用原.env配置，不向浏览器暴露密钥。Streamlit 8501为历史界面，当前新版以原生网站为准。

详细口径、情景参数和算法参考见 [企业财务与融资决策模型](docs/企业财务与融资决策模型.md)。融资比例、利率、费用、现金波动与还款日程含显式假设，不等于真实授信或合同现金预算。

# 融智 Agent · 中小微与科创企业融资决策

聚焦制造类、软件与信息技术类中小微及科创企业。上传必要财报原值，填写外部借款金额、用途和期限，Agent计算指标、检验需求匹配、给出有官方产品依据的条件式拟申请方案，验证压力后复审需求；不合适时另行求解替代方案。原配置DeepSeek API保持不变；模型负责选择工具与解释，Python负责金额、公式和独立验证。

## 使用方法

1. 在“企业与数据”下载分块模板，先填标记的13项必要本期原值，科目在行，本期与上期在列。两期周转细项可选，不需自行算指标。
2. 上传后核对企业、期间、单位和公开来源。缺失留空，真实零值填0。新模板不含授信、合格应收、内部预算、担保估值、CFADS或未来合同还款计划。
3. 在工作台填想向外借多少钱、用途、多久还完及企业服务类型，再选择融资组合、风险分析或方案比较。借款额已扣除自行安排资金，不重复扣账上现金。高级情景首次可保持默认。
4. 生成决策。启用AI时模型选择工具、观察数值结果，执行近期行业地区检索与正文核验；关闭时执行同一组本地模型。
5. 在方案页或报告旁的“融资决策对话”直接问原因、指定试算或采用建议。例如“改成借60万元、36个月还完，比较还款压力”。Agent理解问题后按需调用金融工具，重算、验证并保存版本，页面同步更新；无需回工作台改参数。
6. 在“分析报告”查看核心数据、需求推导、风险、策略和代表压力情景，下载可打印HTML、Markdown及包含执行证据的ZIP。

## 决策模型与Agent工具

新需求流程提供12个工具：数据核验、财务指标、历史需求参照、风险筛查、专业产品知识检索、偿付测算、产品匹配、约束优化、行业地区研究、独立验证、需求复审及替代方案、报告交付。旧版自动需求快照保留11工具的历史兼容。

- 财报推导现金需求参照，与用户借款需求分开。两期周转科目未齐时不补零，使用最近完整年度经营现金流平稳情景，并注明不能细分外推。
- 官方产品登记覆盖小微信用、合作平台、抵押、设备购置与部分科创地方路径。按用途、地区、期限筛选，先尽量覆盖外部借款需求，再最小化假设利息或还款峰值。产品上限从不当作企业已获额度。
- 验证模块独立逐月展开还款表，检查全期限最重12个月的本息。未知还款方式按到期还本保守检查，不假定续贷。原需求不匹配时重新求解更合适金额及期限，替代方案再次验证。
- 三个分析重点分别突出筹资结构、风险与改善临界点、不同策略的取舍。金额相同的方案合并，不硬凑差异。
- AI规划公开模式最多14轮、24次工具调用，失败时明确标识本地续跑；所有数字由工具生成。
- 市场模块保留近期来源检索、正文日期核验和分层替代参考。有效信号可增加压力并重新求解，不会自动调低用户已选择的更强压力。离线重算沿用历史来源时重新核验时效，并说明没有新检索或新模型解释。
- 专业对话调用原配置API，提供读取分析、解释指标、重算方案、采用已验证建议、更新市场依据和比较历史版本六类工具。财报原值锁定，金额及期限单位由服务端独立核对；“少借一点”等含糊要求先追问。
- 可以直接说“比较低成本和抗风险方案”或“重点做风险分析”，由对话切换分析重点并真实调用对应算法，结果随新版本保存。单轮最多6轮规划、10次工具调用、3次重算，避免无界调用。
- 对话的量化卡由Python生成，保留参数、前后比较和真实工具记录。原生版在SQLite按浏览器会话保存最近20轮对话。API失败或必要工具未完成时不保存草稿方案；仅文字校验失败时，丢弃模型文字，明确标识并展示已执行金融工具的核验结论，可保存真实重算的情景版本。旧报告始终保留。原生版刷新页面可恢复对话，Streamlit版保存在当前浏览器会话。

当前公式、13项必要数据、官方产品来源及复审流程见[中小微与科创融资模型](docs/中小微与科创融资模型.md)。此前自动需求模型见[公开报表决策模型说明](docs/公开报表决策模型说明.md)。旧任务快照兼容说明保存在[历史版本功能说明](docs/历史版本功能说明.md)，新任务不再使用内部条件模板。

## 本地启动

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

浏览器打开 `http://127.0.0.1:8501`。Streamlit依赖见`requirements.txt`。独立原生网站使用`requirements-web.txt`，运行`./start-native.ps1`，默认`http://127.0.0.1:8787`，无需Streamlit。

API配置继续读取原`.env`中的`DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`等兼容变量，密钥不进入浏览器或报告。没有API也能做本地模型分析。公网部署未完成，本机地址不能作为评委远程访问链接。

## 结果边界

财报不能直接给出真实授信、可融资债权、可用担保物或未来还款日程。用户借款需求与历史推导缺口分开保存；可投入现金、维持性支出与存量本息包含显式代理估算，覆盖倍数不能称为真实合同DSCR。数学验证通过不证明银行可批准。当前新流程限定制造类及软件信息技术类完整年度报表，初始产品库覆盖有限，没有行业实证校准，也不验证月内季节性现金安全。费用未纳入，不表示实际免费。
